# Android v2.4 UI revision implementation plan

> For implementation agents: use subagent-driven-development in isolated worktrees, then independent SPEC and QUALITY reviews.

**Goal:** Match the user's real phone feedback: attach two quick actions to the original skill arc, move the bare map visibility icon to the upper left without covering the performance panel, match native Sort and Store button sizes, and replace both touch-margin selectors with real sliders.

**Architecture:** Native geometry owns quick-button draw and hit positions. Java publishes actual performance-panel bounds and draws the original map art without its surrounding circle. The original game widgets continue to own inventory buttons and Custom controls; applied settings and persistence keep their existing contracts.

**Technology:** Android Java Canvas/JNI, C touch bridge and native game widgets, shared Python overlay generators. Reference original project: jhaizhou-ops/d2r-mobile, reviewed e3756f8942b40eba6c851e881828a5b1bda17fd6.
